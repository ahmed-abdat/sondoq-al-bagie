# المصطلحات (Glossary) · owner decisions 2026-09-30

One word for one thing, on every screen, sheet, toast, report (images, PDF, text) and notification.
Simple everyday Arabic, correct grammar. Change a term here first, then everywhere.

| Concept | Use | Never use |
|---|---|---|
| Money coming into the fund | **المداخيل** · «مجموع المداخيل» | ما دخل، دخل، الإيرادات، المداخل |
| Money going out | **المصاريف** · «مجموع المصاريف» | ما صُرف، صرف |
| The amount a member owes each month | **المستحقات الشهرية** (one month: «مستحقات شهر مايو») | الرسوم الشهرية، الاشتراك، الرسوم |
| The fee amount per group | «المستحقات الشهرية: 1 000 أوقية» | |
| Unpaid past months / levy shares | **المتأخرات** | الديون |
| Mandatory levy | **لوحة** (plural لوحات) · «نصيب اللوحة» | مساهمة إلزامية |
| Optional donation campaign | **تبرع** (plural تبرعات) · the money given: «مساهمة» | حملة (except in code) |
| Fund balance | **الرصيد** · «رصيد أول السنة» / «رصيد آخر السنة» · «في الصندوق» on home | |
| Report total incl. money held by تبرعات/لوحات | «المجموع آخر السنة» → «منها في الصندوق» + «منها لدى التبرعات واللوحات» | |
| Fee group | **الفئة** (أ، ب، ج…) | المجموعة (for fees) |
| Committee roles | **المسؤول** · **عضو اللجنة** | أمين الصندوق، نائب، مشرف |
| Recording money | «سجّل دفعة» · «سُجّلت الدفعة» · «تراجع» | أكّد، وصل |
| Cancelling | «ألغِ» · «أُلغيت» + السبب | احذف |
| Expense activity | **النشاط** (list managed by المسؤول) | المحور |
| The teaching activity | «التدريس المحظري» | «التدريس المحوري» |
| Units | «أوقية» (old ouguiya); the report note «المبالغ بالأوقية القديمة» once | |

Monthly charts: income is shown **by the month it pays for** (مستحقات يناير in January, whatever
day it was recorded); expenses by their date. Label: «المداخيل حسب الشهر المستحق».
